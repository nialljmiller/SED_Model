# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SED_Model, please report it privately. Do not open a public GitHub issue for security-sensitive reports.

**Options:**

- **Email:** niall.j.miller@gmail.com
- **GitHub:** Use GitHub's private vulnerability reporting feature, if enabled for this repository.

Include as much detail as possible:

- Description of the vulnerability
- Steps to reproduce it
- Affected version or commit
- Any known impact
- Any suggested mitigation, if available

## Disclosure

Please give the maintainer reasonable time to investigate and address the issue before any public disclosure.
