
# SED_Model — Code of Conduct

## Scope

This Code of Conduct applies to all SED_Model project spaces, including the repository, issue tracker, pull requests, discussions, and any communication channels associated with the project.

## Standards

Behaviour that keeps this project functional and productive:

* Communicating clearly and respectfully
* Giving and receiving technical criticism constructively
* Staying on topic
* Assuming good faith where reasonable
* Focusing discussions on reproducible scientific and software behaviour

Unacceptable behaviour:

* Harassment, personal attacks, or sustained hostility toward contributors
* Deliberate disruption of technical discussions
* Publishing others' private contact information without consent
* Repeatedly ignoring maintainer instructions
* Submitting intentionally misleading, unsafe, or malicious code

## No Warranties

Participation in this project, including any contributions, advice, or code, comes with no guarantees of any kind. See the project license for full terms.

## Enforcement

Violations may be reported to **[niall.j.miller@gmail.com](mailto:niall.j.miller@gmail.com)**. Reports will be reviewed at the maintainer's discretion.

Possible enforcement actions include:

1. **Warning** — A private written warning explaining the violation and expected change in behaviour.
2. **Temporary restriction** — Temporary removal from project discussions or contribution spaces.
3. **Ban** — Removal from the project and associated spaces, temporary or permanent, depending on severity.

The maintainer has final say on enforcement decisions.
